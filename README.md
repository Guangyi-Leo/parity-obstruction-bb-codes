# Stab-QRAM: A Clifford-Only Quantum Oracle for Affine Boolean Data

Reproducibility package for the paper *Stab-QRAM: A Clifford-Only Quantum
Oracle for Affine Boolean Data* (arXiv:2509.26494).

This repository contains the Stab-QRAM compiler, all verification and
case-study scripts, the schedule census, and the `stim` and SABRE
experiments. A single entry point (`run.sh`) reproduces every figure and
table in the manuscript from fixed seeds.

---

## Repository layout

```
.
├── run.sh                              # one-command reproduction of all results
├── requirements.txt                    # Python dependencies
├── experiments/
│   ├── verify_depth_theorem.py         # core compiler + Theorem 1 (exact depth D*) check
│   ├── make_fig_architecture.py        # Fig. 1  compilation-pipeline schematic
│   ├── regenerate_main_figures.py      # Figs. 2-4 + SI Fig. S1 (depth, rank, locality, gate count)
│   ├── case_studies.py                 # Case studies I-III + Figs. 5-7
│   ├── topology_distance.py            # SI Table S2  locality proxy: grid vs random-regular
│   ├── sabre_routing.py                # SI Table S3  ground-truth SABRE routing (needs qiskit)
│   ├── hook_schedule_census.py         # SI Table S4  proper-coloring / hook-orientation census
│   └── stim_circuit_distance.py        # SI Table S4  circuit-level distances (needs stim)
├── results/                            # raw statistics in JSON / CSV (regenerated by run.sh)
└── figures/                            # compiled PDF figures (regenerated by run.sh)
```

The compiler itself lives in `experiments/verify_depth_theorem.py`
(`dstar` and `koenig_schedule`); the other scripts import it.

## Installation

Requires Python 3.10+.

```bash
python3 -m venv venv
source venv/bin/activate          # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

`numpy`, `matplotlib`, and `networkx` are required for the core results.
`qiskit` (SABRE routing) and `stim` (circuit-level distances) are optional;
the corresponding steps are skipped automatically if they are not installed.

---

## Reproducing all results

```bash
bash run.sh
```

This runs all seven steps in order and writes raw statistics to `results/`
and PDF figures to `figures/`. Total runtime is roughly 10-15 minutes on a
laptop-class CPU (the schedule census and circuit-level distance search
dominate). Every script takes a `--seed` argument; the seeds baked into
`run.sh` are exactly those reported in the manuscript Methods section
(5, 7, 11, 17, 23).

### Running individual experiments

```bash
# Theorem 1: exact scheduled depth D* (proper coloring + exhaustive optimality)
python3 experiments/verify_depth_theorem.py --instances 500 --seed 7

# Figs. 2-4 and SI Fig. S1
python3 experiments/regenerate_main_figures.py --seed 5

# Case studies I-III and Figs. 5-7
python3 experiments/case_studies.py --seed 17

# SI Table S2: static locality proxy, grid vs random-regular
python3 experiments/topology_distance.py --instances 20 --seed 11

# SI Table S3: ground-truth SABRE routing (requires qiskit)
python3 experiments/sabre_routing.py --n 25 --densities 0.10 0.25 0.50 \
    --instances 20 --seed 11

# SI Table S4: schedule census and circuit-level distances (stim for the latter)
python3 experiments/hook_schedule_census.py --d 3 5 7 --samples 200 --seed 23
python3 experiments/stim_circuit_distance.py --d 3 5 --samples 12 --seed 23
```

## Notes on the results

- All compiled Stab-QRAM circuits are computational-basis-preserving and are
  verified by exact classical simulation of the layered gate list; Case II
  additionally forms the full block-encoding unitary and compares it against
  the analytical matrix to machine precision.
- The locality proxy (`topology_distance.py`) is an optimistic static model;
  `sabre_routing.py` provides the ground-truth routing overhead that the
  manuscript reports alongside it.
- The schedule census (`hook_schedule_census.py`) samples random proper
  4-edge-colorings by randomized greedy assignment; this sample is **not**
  uniform over all proper colorings, as disclosed in the Supplementary
  Information. The circuit-level distances (`stim_circuit_distance.py`) are
  computed by `stim`'s exhaustive graphlike-error search.

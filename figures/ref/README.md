# Reference figures — provenance only

The five figures studied while designing ours are **not** redistributed here.
One is CC BY-NC-ND 4.0 and one carries the arXiv non-exclusive licence with no
reuse right, so republishing them in this repository would not be permitted.

`SOURCES.md` gives the DOI/arXiv link, the figure number, the licence and the
exact crop for each, so anyone can fetch them from the publisher. Nothing in
`figures/` is traced or adapted from them; only layout conventions were studied.

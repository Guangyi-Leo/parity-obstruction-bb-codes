> **Theorem S2.** Let QC(A,B) have distinct sums, |A| = k ≥ 3 and |B| = ℓ with **k and ℓ odd**, and suppose a proper schedule of depth Δ = k + ℓ has a = (ℓ+1)/2. Then no such schedule exists.

## B. Strengthened statements (with proofs)

### B.1 Corollary 1′ — Theorem 1 for two-block codes, with the component structure

> **Corollary 1′.** Let QC(A,B) be a two-block code over G with |A| = k, |B| = ℓ, and let H ≤ G be the subgroup generated by the differences a_s − a_{s'} and b_t − b_{t'}. The connected components of the Tanner graph are indexed by the cosets of H: the component of X_g consists of the checks X_{g+H}, Z_{g+a_1+b_1+H} and the data qubits L_{g+a_1+H}, R_{g+b_1+H}, so it has |H| checks of each type and 2|H| data qubits. Consequently, **if |H|·kℓ is odd, no proper schedule of depth k + ℓ exists.** For a connected Tanner graph (H = G) the condition is that N, k and ℓ are all odd; for bivariate bicycle codes with k = ℓ = 3 it is ℓm odd.

*Proof.* X_g shares a data qubit with Z_{g'} iff g' − g ∈ Σ := {a_s + b_t}. Hence the X-checks reachable from X_g are X_{g+H'} with H' = ⟨σ − σ' : σ, σ' ∈ Σ⟩, and H' = H because a_s − a_{s'} = (a_s + b_t) − (a_{s'} + b_t) and conversely every σ − σ' is a sum of an a-difference and a b-difference. The L-qubits of X_{g+H} are L_{g+a_s+H}, a single coset because a_s − a_{s'} ∈ H; likewise for the R-qubits and the Z-checks. Every data qubit has r_v s_v = kℓ, so Σ_v r_v s_v over the component equals 2|H|kℓ ≡ 2 (mod 4) iff |H|kℓ is odd, and Theorem 1 applies. ∎

Remarks. (i) The subgroup H is the same subgroup whose image ε(H) is the group M of Theorem 3, so Theorems 1 and 3 are both statements about H. (ii) The Z₆ instance A = B = {0,2,4} has H = {0,2,4}, |H| = 3, which is the "components of six data qubits" of Section III D. (iii) In the enumeration of Section III D every instance with N odd (all of Z₉, Z₃×Z₃, Z₅, Z₇, Z₃×Z₃ …) is already excluded by Corollary 1′ whenever its Tanner graph is connected; Theorem 7 is needed only for even N.

### B.2 Corollary 1″ — beyond two-block codes

> **Corollary 1″.** Let a CSS code have every data qubit with exactly w X- and w Z-neighbours and every X-check of weight 2w. If a connected component of the Tanner graph contains n₀ data qubits with w odd and n₀ ≡ 2 (mod 4), then no proper schedule of depth 2w exists.

*Proof.* Σ_v r_v s_v = n₀ w² ≡ 2 (mod 4). ∎

Example. The hypergraph product of a (3,3)-regular classical code of odd length n_c with itself has 2n_c² data qubits, all of type (3,3), weight-6 checks and (for the circulant codes below) a connected Tanner graph, so depth 6 is impossible: H = circ(1 + x + x³) of length 7 gives a [[98,18]] code, length 15 gives [[450,32]] (`hgp.py`). Depth 7 for the [[98,18]] code: see `hgp_sat.log` (SAT run).

### B.3 Lemma A (2-height), the reduction of Proposition 11, and Theorem 12′

For d of even order let the **2-height** h(d) be the largest h with d ∈ 2^h G (finite exactly when ord(d) is even: d ∈ 2^j G for all j iff d lies in the odd-order subgroup).

> **Lemma A.** If ord(d) is even with 2-height h, there is a homomorphism ε : G → Z_{2^{h+1}} with ε(d) = 2^h.

*Proof.* Put q = 2^{h+1} and Ḡ = G/qG ≅ ⊕_i Z_{2^{e_i}} with e_i ≤ h+1. The image d̄ of d is non-zero (d ∉ qG) and 2d̄ = 0 (d ∈ 2^h G), so d̄ = Σ_i c_i with c_i ∈ {0, 2^{e_i−1}} and some c_{i₀} ≠ 0. Compose G → Ḡ → Z_{2^{e_{i₀}}} with x ↦ 2^{h+1−e_{i₀}} x ∈ Z_q; then d ↦ 2^{h+1−e_{i₀}} · 2^{e_{i₀}−1} = 2^h. ∎

**Reduction of the keys.** Fix q = 2^{h+1}. Under such an ε the key of a class-C1 code has d̄ = q/2. Relabel so that the collision is {(1,1),(2,2)} and normalise α₁ = β₁ = 0; the collision equation then forces α₂ = β₂ = q/2, so the key is

  κ_q(a,b) = (0, q/2, a ; 0, q/2, b),  a = ε(a₃), b = ε(b₃) ∈ Z_q

(q² keys per modulus instead of 18q³). Three symmetries of the class system identify further keys: (a,b) ~ (b,a) (A ↔ B with L ↔ R), (a,b) ~ (ωa, ωb) for every unit ω of Z_q (T′(c) = T(ω⁻¹c)), and (a,b) ~ (a + q/2, b + q/2) (swap labels 1 ↔ 2 and renormalise). Finally the class-system constraints only connect classes that differ by key elements, so the system for κ_q(a,b) is a disjoint union of copies of the system on the subgroup M = ⟨q/2, a, b⟩ = ⟨g⟩, g = gcd(q/2, a, b), each copy being the class system of modulus q/g with key κ_{q/g}(a/g, b/g) — again "d̄ = half the modulus". Hence it suffices to treat keys generating Z_q, i.e. gcd(a,b) odd; after a swap and a scaling, a = 1. Everything therefore reduces to the one-parameter family

  **F_q = { κ_q(1, b) : b ∈ Z_q }.**

> **Proposition 11′ (computer-verified).** For q ∈ {2, 4, 8, 16, 32} every key κ_q(a,b) with d̄ = q/2 admits a class schedule: all 2, 5, 11, 21, 39 inequivalent keys (under the three symmetries above) are satisfiable, and in particular every member of F_q (checked separately for all b at q = 8 and q = 16). At q = 64 the first 5 of 73 representatives were satisfiable when the run was stopped (individual instances take up to ~30 min with CaDiCaL on one core; a kissat run of the remaining 68 is the natural next step and would give d ∉ 64G).

Cross-check of Table S2 with an independent encoder of (i)–(iv): q = 2: 144 keys, 72 admissible, all with d̄ ≠ 0, |M| = {2}; q = 3: 486 keys, none admissible; q = 4: 1152 keys, 864 admissible = exactly the keys with d̄ ≠ 0, |M| ∈ {2,4} — identical to Table S2.

> **Theorem 12′.** Let QC(A,B) be of class C1 with collision element d of even order and 2-height h(d) ≤ 4, i.e. d ∉ 32G. Then the minimum CNOT depth of a proper single-round interleaved schedule is exactly 6.

*Proof.* Lemma A gives ε with ε(d) = 2^h ≠ 0 in Z_{2^{h+1}}, 2^{h+1} ≤ 32; Proposition 11′ and the reduction give a class schedule for the key of the code; Lemma 10 pulls it back. The degree bound gives the lower bound. ∎

This covers all 265 even-order class-C1 instances of the data set, including the two Z₃₂ instances with d ∈ 8G (2-height 3, modulus 16), without instance-by-instance witnesses.

> **Conjecture (sharpened form of "even order suffices").** For every j ≥ 1 and every b ∈ Z_{2^j} the key κ_{2^j}(1,b) admits a class schedule.

Negative structural findings (useful to state so that readers do not look for them): no class schedule for the keys of F_q with q ≥ 8 has the form T(c + q/2) = σ(T(c)) for any fixed permutation σ of the six layers (also not with σ depending on the edge type), nor T(c+2) = σ(T(c)); and for q = 16 the schedule cannot be a function of (c mod 2, ⌊4c/q⌋) or (c mod 4, [c ≥ q/2]) except for special b. The dependence on c mod 2^j is essential, which is why an analytic template family has not been found.

### B.4 Lemma 10 — the sentence on coincidences, expanded

> Every constraint of QC(A,B) is indexed by a labelled object: (i) by a check, (ii) by a data qubit, (iii) by an overlapping pair together with its unique label pair (s,t), (iv) by the collision pair together with its two label pairs. Under ε each of these is the pullback of the corresponding class constraint at class ε(g): the constraints (i)–(ii) at X_g, L_h, R_r are the class constraints at ε(g), ε(h), ε(r) evaluated at T(ε(·)), and the code constraint of the pair (X_g, Z_{g+a_s+b_t}) is the class constraint (iii) for (ε(g), s, t) [or (iv) for the collision]. Additional coincidences among the projected sums ε(a_s) + ε(b_t) create no constraint in QC(A,B), whose overlapping pairs are determined by the sums in G, and they remove none, because (iii) is imposed for every class and every label pair rather than for class-level pairs.

### B.5 Table I versus the published cycle (resolves the open sentence in S7)

In the notation of the paper, Table 5 of Ref. [5] (rounds 1–7 as CNOT layers; A_s ↔ label s, B_t ↔ label t) is

  X L-edges (6, 2, 7), X R-edges (4, 3, 5), Z L-edges (3, 4, 5), Z R-edges (1, 6, 2).

It is a proper translation-invariant depth-7 schedule (F₂ simulation on [[72,12,6]] and [[144,12,12]]) with o_L = o_R = [s = 2]; Table I has o_L = o_R = [s ≤ 2]. The two are **not** equivalent under label permutations, layer reversal, X/Z duality and block swap (a group of order 288 acting on labelled schedules): the 8496 translation-invariant proper depth-7 schedules fall into 41 orbits under this group, and Table I and the published cycle lie in different orbits (`bravyi_cycle.py`). Both attain the exact minimum 7 of Corollary 9.

## D. Verification protocol for class schedules with degenerate keys (referee point 2.5)

For a key with repeated entries (α_s = α_{s'} or β_t = β_{t'}; unavoidable at q = 2 and for 648 of the 864 admissible keys at q = 4) the naive pullback QC(ε(A), ε(B)) over Z_q is not a two-block code with three-element sets. Each stored class schedule should therefore be checked (a) directly against (i)–(iv) and (b) by pulling it back to a *realising* class-C1 code: choose M, lifts a_s = α_s + q x_s, b_t = β_t + q y_t ∈ Z_{qM} with exactly the designated collision (and no other), and run the F₂ circuit simulation of the pullback along g ↦ g mod q. Done for all 72 keys at q = 2 (M = 7, codes over Z₁₄) and all 864 keys at q = 4 (codes over Z₂₈): 936/936 pullbacks are proper (`pullback_demo.py`).
